# Practical Psychology Consultancy

Modern Astro site for Practical Psychology Consultancy Ltd.

## Commands

```bash
pnpm install
pnpm dev
pnpm build
pnpm preview
```

Static assets live in `public/assets`. Shared page copy, services, resources, and publication data live in `src/data/site.js`.

SEO metadata and structured data live in `src/data/seo.js`. The site generates `/sitemap.xml`, `/robots.txt`, `/llms.txt`, and `/llm.txt` during the Astro build.
